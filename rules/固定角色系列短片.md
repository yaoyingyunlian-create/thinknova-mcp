# 规则 · 固定角色系列短片（方法；内容由用户定）

> 用途：连上 ThinkNova 的 AI（文生图 generate_image / edit_image + 图生视频 animate_image + 本工具包的 render / publish）制作固定角色、多镜头连贯的竖版短片。长片拼接、字幕、配音、发布和分段修改均是本机后续工作，不由 MCP 自动承诺或执行。
> 本模板只写方法，不提供任何内容默认值。角色、故事、台词、音色、风格、配乐、片尾全部由用户定。

---

## 一、用户要填的（模板不给内容默认值）

| 项 | 填什么 |
|---|---|
| 角色 | 这里填用户要的角色（每个写清外形、标志性服装和道具；主角 1 个，配角若干） |
| 换不换装 | 这里填用户要的（系列里角色会不会换衣服） |
| 故事 / 本集主题 | 这里填用户要的 |
| 台词 / 旁白文字 | 这里填用户要的（按镜头分段，写清谁说） |
| 音色 | 这里填用户要的（不指定 = 视频模型自己出声；指定了某个音色或克隆音 = 单独配音） |
| 语言 | 这里填用户要的（台词语言；字幕可加第二语言） |
| 画面风格 | 这里填用户要的 |
| 总长度 | 这里填用户要的（按实际镜头、积分和本机编辑能力拆分） |
| 字幕样式 | 这里填用户要的（字号、颜色、位置、关键词标色） |
| 角标 / AI 标注 | 这里填用户要的（发布平台要求 AI 标注时必须保留） |
| 配乐 / 音效 | 这里填用户要的 |
| 片尾 | 这里填用户要的 |
| 用户自己的素材 | 这里填用户给的（产品照、店内照、自己拍的视频；没有就空着） |

**技术参数（可留默认，用户可改）**：画幅 9:16；单镜时长和输出规格以 MCP 实际返回的默认模型能力为准。只有实际素材原生支持时才可称为 1080×1920；本机放大不增加生成细节。

## 二、方法（照做）

### 1. 用多视图锁住角色（每个角色只出一张）
1. 用文生图给每个角色出**一张**多视图设定板，之后整个系列都用这一张；同一角色⛔ 出多种版式、⛔ 反复出。
2. 版式按「换不换装」选：
   - **不换装**：上排「正面近景 + 标准侧面近景」（五官、脸型、耳朵、花纹、领口清楚）；下排「正面 / 侧面 / 背面全身远景」（服装结构、颜色、材质、配饰、身体比例）。
   - **换装**：横向四栏——正面 / 侧面 / 背面全身（脸部留白）+ 最右一栏脸部近景特写。
3. 提示词必须写：「所有视图中角色外形、颜色、服装严格一致」「背景干净均匀，柔和正面光」「画面里不要出现任何文字、字母、数字、标志、水印」。
4. 验收：各视图是同一个角色、没有文字、道具位置一致；不合格改提示词重出 1 次。

### 2. 每镜首帧怎么出
1. 文生图，按画幅出图；参考图按角色、场景、产品排序，单次最多 3 张。创建结果必须回读 `reference_handling`；若为 `first_only`，只可把首图视为已生效参考。
2. 提示词结构：「图一是 X 的多视图参考，严格保持外形 / 颜色 / 服装不变」→ 场景（地点、时间、光线、关键道具）→ 角色在做什么、表情 → 构图（中景 / 特写、角色在画面哪个区域）→ 用户要的画面风格 →「画面里不要出现任何文字、字母、数字、招牌字、标志、水印」。
3. 同一场景出现多次：把该场景第一次出的首帧也当参考图，保证是同一个场所、同一组道具。
4. 技术说明：图像模型写字（尤其中文）常出乱码假字，建议生成图里不放要读的字，招牌、卡片上的字后期本地排版。

### 3. 用图生视频出镜头（统一一个模型，单镜 10 秒）
1. 全片统一用一个「首帧跟随最准」的图生视频模型。**第 1 镜先单独试**：接住首帧、角色没走样，再提其余镜。
2. 单镜时长按默认模型实际能力决定；比台词段长的部分可后期剪掉，短了应重做镜头或使用明确的本地后期编辑，禁止用末帧定格伪造时长。
3. 参考图：首帧放第一张，角色设定板放后面。技术说明：有的平台建单后把第一张图单独存成「首帧」字段、其余存成参考图；重提或复用旧单时，首帧要从「首帧」字段取，⛔ 从参考图列表里取第一张（那是设定板，拿它当首帧就接不上）。提交后回读一次：首帧字段的尺寸应是竖版首帧，不是方形设定板。
4. 提示词结构（这一镜有台词时，台词写法见第 5 步）：
   「No background music.（有台词时）/ Image 1 is the first frame: continue exactly from it, same framing and same characters」→ 角色设定板说明 → 按秒写动作（0–3s / 3–6s / 6–10s，每段一个动作，对应这一镜的台词）→ 尾句：「No text, letters or numbers anywhere; keep every sign blank. Keep the character's design exactly as in the reference sheet.」
   这一镜没有台词：尾句前加「No talking, no lip movement, no dialogue; only quiet ambient sound.」
5. 失败处理：报生成失败 → 原样重提 1 次；仍失败或接口报错 → 停下报告，⛔ 连刷。

### 4. 镜头之间怎么接（按实际镜头能力拆分）
1. 镜头数 N ≈ 总长度 ÷ 10 秒；先写镜头表，每镜标明：场景、角色动作、对应台词、首帧来源（新生成 / 接上一镜尾帧 / 锚定重生成 / 用户素材）。
2. **同一场景的连续动作 → 首尾帧衔接**：取上一镜视频最后一帧 → 上传 → 当下一镜首帧。写上一镜提示词时，把它的最后 2 秒安排成下一镜的起始姿势。
3. **换场景 → 新生成首帧**（第 2 步）。
4. **回到出现过的场景 → 新首帧时把那个场景的首帧当参考图**。
5. **防走样（长片关键）**：
   - 每出完一镜，拿最后一帧和设定板并排比对（外形、颜色 / 花纹、眼睛、服装、道具）；
   - **连续首尾帧衔接到第 4 镜，或任何一镜发现走样**，下一镜改为「带设定板重新生成首帧」锚定，再继续往下接；
   - 长镜头拼接与连续性仅为本地编辑建议，不承诺自动无缝拼接或绝对角色、声音一致性。
6. **模型开头自己切镜**：首帧传对了，视频第 0 帧却直接换成近景 / 另一个机位（实测提示词里有「举手机拍」「换角度」这类动作时会发生）。剧情接得上、角色和设定板一致 → 当一个剪辑切镜用，下一镜从它的尾帧接；要无缝接时，提示词加「keep the same framing as image 1 for the first 2 seconds」重出。

### 5. 声音（台词默认由视频模型一起出）
1. **用户没指定音色**：台词直接写进这一镜的图生视频提示词，视频模型连画面带声音一起出，不另外配音。
   - 写法：提示词用英文写动作和镜头，台词原文（用户的语言）放进「」引号；每句台词写清从第几秒起、谁说、什么声音（例：The off-screen narrator, a gentle female voice speaking Mandarin Chinese, says: 「…」）。全片每一镜的声音描述用同一句话，一字不改。
   - 声音描述要写到「年龄 + 性别特征 + 音高方向 + 语气 + 语速」，并写明不要的方向，例：a gentle young adult woman's voice speaking standard Mandarin Chinese, clearly feminine, light and clear, medium-high pitch, never deep or low, soft and warm, calm bedtime-story pace, the same narrator voice used in every episode。只写「温和女声」或「中音」时，各镜音高会散得很开（实测一集里从 160 到 250 Hz）。
   - 每镜台词量按约 4 字 / 秒估，10 秒一镜不超过约 40 字（最好 ≤35 字留停顿）；超了这一镜改出 15 秒，或拆到下一镜。
   - 要音效（门铃、碰杯等）时，音效放在旁白开口之前（例：0–0.8 秒音效，旁白从 1 秒起），⛔ 和第一句台词叠在同一秒——会盖住第一个字，识别和观众都听错。
   - 片中有没有声音的画面（真实录屏、产品实拍、用户自己的视频）：把那段的旁白写进相邻一镜的台词一起生成（那一镜改出 15 秒），拼片时这一镜画面只用前半，后半的声音铺到无声画面上，声音不会突然换人。
   - 加「No background music」，否则模型可能自带配乐盖住人声。
   - 技术说明：目前不支持口型同步，角色正脸开口时口型和声音对不上，建议写成画外旁白、角色不开口；要不要让角色说话由用户定。
2. **用户指定了音色（含克隆音）**：视频按「没有台词」写（第 3 步尾句），台词用指定音色单独配：逐句生成、去首尾静音、按镜头段拼，段落之间、问句和转折之后留停顿。
3. 验收（两种都要）：逐句语音识别回听，只有同音字差异算通过，读错就改词重出（多音字先绕开）；没有配乐盖人声；**全片各镜是不是同一个声音**。
4. 各镜声音不一致时：说明差异并让用户决定重做或本地配音；不承诺固定次数免费重抽、双版本或绝对声音一致。
5. 量声音是否一致：每镜取人声算音高中位数和长时频谱，两两比相似度；同一个声音约 ≥0.95，不同人约 0.70–0.85。人耳最后听一遍全片为准。

### 6. 拼成片
1. 每镜视频按对应台词段时长剪（取动作最完整、台词完整的那一段，⛔ 剪掉半句），镜头之间硬切或短淡化。
2. 声音：台词由视频模型出的，保留视频原声；单独配音的，去掉视频原声铺配音。再按用户要的铺配乐 / 音效（配乐低于人声）。
3. 按用户要的字幕样式上字幕（按小句切、去标点、每屏行数受控），上用户要的角标和片尾。
4. 按技术参数输出。

### 7. 成片检查（全过才发）
1. 无人声时长（默认值，用户可改；不需要一直有人声的片子可关掉这项）：前 20 秒内最长无人声 ≤3 秒，最后一句后无人声 ≤4.5 秒。
2. 逐句语音识别和原文对照，只允许同音字差异；全片听一遍，各镜声音是同一个人。
3. 每秒一帧联系表：字幕不出画面、不压主体；**每一镜角色都和设定板一致**；画面里没有生成出来的乱码字；用户素材里的字（产品型号、数字）没走样。
4. 违禁词扫描（发布平台自己的规则词表 + 绝对化用语）。
5. 发布平台要求的 AI 标注全程可见。

### 8. 发布
1. 用本工具包的发布脚本（命令见 AGENTS.md 第 6 步，先演练再真发）按用户要的平台和时间排定时发布；标题、描述、话题按平台规则写，勾平台的 AI 内容声明。
2. 发布前回读：定时时间、标题、AI 声明都对上才算排好；发出后回读一次确认已上线。
3. 系列连续发时，每集用同一张设定板、同一套技术参数，集数角标递增。

### 9. 分段修改（用户要改某个画面时）
成片是一镜一镜拼起来的，改哪里就只重做那一镜，其余镜头不动，重做好再重新拼。
1. 先在镜头表里找到要改的那一镜，看它的首帧来源。
2. **这一镜的首帧是独立生成的**（新生成 / 锚定重生成 / 用户素材）：按用户的修改改首帧提示词或视频提示词，直接重出这一镜。
3. **这一镜是首尾帧接起来的**（它的尾帧是下一镜的首帧）：改完后，接在它后面的镜头二选一——
   - 一起重做：从这一镜往后，凡是首尾帧接着的镜头依次重做，直到遇到下一个独立首帧的镜头为止；
   - 或者重新锚定：下一镜改用「带设定板重新生成的首帧」，和改好的这一镜重新接上，再往后的镜头不动。
4. 设定板是整个系列的基准：只改某一镜的表情、动作、场景时，设定板不动；用户要改角色本身的外形，就是换了角色，先重出设定板，再把所有镜头重做。
5. 重新拼片：替换改过的镜头；台词是视频模型出的，改台词就重出这一镜；单独配音的只重配那一段。
6. 改完只检查这一段和前后两个接缝：角色和设定板一致、动作接得上、声音像同一个人、字幕没错位、这一段的无人声时长和语音识别对照。

### 10. 拼入用户自己的素材
用户给了产品照、店内照或自己拍的视频时，按素材类型选做法，在镜头表里把这一镜的首帧来源标成「用户素材」。
1. **产品照 → 当参考图出首帧**：首帧提示词写「图一是用户的产品，外形、颜色、接口、机身上的字和数字严格保持不变」，再写陈列场景；图生视频提示词再写一次「产品上的字和数字全程不变」。验收：首帧和视频里产品的字、数字、颜色都和原图一致。
2. **店内照 → 先看比例**：
   - 先按输出画幅（9:16）裁出主体；裁得下（主体完整）→ 直接当首帧做图生视频，提示词写「同一个房间，不增不减任何物件」。
   - 裁不下（横图主体太宽）→ ⛔ 直接塞进竖版（模型会自己往上下补画面，补出来的是编的）；改为当场景参考图，用文生图出一张同房间、同家具的竖版新首帧，再做图生视频。
3. **用户自己拍的视频 → 统一规格后直接剪进去**：统一成输出分辨率 / 帧率，去原声（台词另出）；要和 AI 镜头接上，就截用户视频最后一帧 → 上传 → 当下一镜首帧，提示词写同一场景接着动。
4. 验收：用户素材和 AI 镜头的接缝顺（首尾帧几乎一致）；AI 段颜色和用户素材差得明显时，在拼片时给 AI 段调色贴近用户素材。
5. 素材边界：只用用户确认可以用的素材；有真人脸、儿童、私人生活照的，先问用户，不确认不用。
