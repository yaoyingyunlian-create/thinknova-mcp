# 固定角色系列短片制作方法

此文件是制作方法，服从 AGENTS.md、服务器账户规则和用户已确认预算。角色、故事、风格、台词、字幕和配乐由用户决定。每镜生成由 MCP 完成，本机负责编辑、字幕、检查和经确认的发布；不承诺无限时长、自动无缝拼接或绝对一致性。

## 一 规划与授权
先读取规则和本地记忆，确定目标、受众、平台、画幅、素材授权、审核方式和预算。按实际能力拆镜，镜头表记录场景、角色动作、台词、首帧来源、参考素材、请求号和结果文件。不要硬编码单镜10秒/15秒或最高分辨率。
固定角色可先生成一张多视图设定板，按用户规则检验外形、服装和道具；无固定角色需求时跳过。设定板变更需记录版本，不能不告知用户地替换。

## 二 首帧与参考
生成首帧时可按角色、场景、产品排列最多三张已授权参考。图生视频的第一张必须是本镜竖版首帧，后面才放角色设定或场景参考。按响应 applied_reference_asset_ids 判断真实生效素材；first_only 时仅首图生效。
场景复用、设定板和上一镜尾帧只是连续性手段，不能保证身份或场景完全相同。生成图中的品牌文字、型号、数字不保证准确；需要精确展示时优先使用用户授权原素材或本地排版。

## 三 镜头生成与重做
先检查一镜的角色、场景、运动、声音和规格，再在既定预算内制作其他镜头。同场连续动作可提取上一镜末帧并上传作为下一镜首帧；换场或走样时重新锚定首帧。
网络重试沿用原 client_request_id，进行中查原 task_id。终态失败、改提示词、质量重做均不得当作免费重抽；新任务使用新请求号，说明费用并检查已授权预算，超出时先询问。
镜头不足应拆分、重新生成或本地编辑；禁止以末帧定格伪造镜头时长。依赖旧镜头尾帧的后续镜头可能要一起重做，先说明依赖与费用，不能宣称改一镜永不影响其他镜头。

## 四 声音与台词
只有实际生成能力支持时才能期待同步声音。声音描述与台词作为创作意图，不保证跨镜同一音色、口型或逐字无误；不提供未经验证的声学相似度阈值。
按语言、停顿和实际语速规划台词。语音识别结果需与定稿逐句比对并回听，品牌、价格、数字、否定词尤其不能仅按同音放行。无法确认则标为待审核，不无限自动重做。
用户指定音色、独立配音、克隆音或双版本属于额外能力和授权需求；必须先确认可用工具、素材权利与预算，不能承诺现有 MCP 自带这些工具。

## 五 本机编辑与检查
保留来源素材与镜头表，按动作和台词完整性剪辑、拼接、排字幕、混音，使用 loudnorm.py 和 check.py。实际尺寸、帧率、时长以文件检测为准；放大转码不会提高生成细节。
逐镜检查人物/产品/店铺、素材权利、字幕位置、文字数字和声音；自动检查通过不等于人工内容检查完成。无法通过的项记录具体原因，不能假报通过。

## 六 确认与记录
发布前按 AGENTS.md 展示成片、标题文案、封面、平台账号和带时区时间，取得当次明确确认。YouTube --dry 仅本地检查，--execute 才实际上传；其他平台演练可能上传素材或产生草稿。
发布后回读内容 ID和状态。异常先核实是否已发出，再决定后续操作；记录任务、费用、确认版本、发布事实和待办，不保存密码、Token或签名链接。

## English summary
Plan shots using actual capabilities and an authorized budget. Keep asset consent and a versioned character sheet when needed. For animation the true first frame comes first; honor all_applied/first_only. No fixed duration, perfect identity/voice/text guarantee, numerical similarity threshold or free retries. Poll existing tasks; new paid generations require a new request and budget authorization. Transcribe AND listen to dialogue. Check local edits and require explicit approval for each real upload/publication. Preserve facts and never store credentials.
