# 学习规则（参考片、店主意见、发布数据）

> 11-12 版。做法就是我们自己学东西的做法：看原件、拆开、写成规矩、用一次、看结果、改规矩。

## 〇、三条总则
1. **看原件再下结论。** 没看到画面、没听到声音，就不说「学会了」。⛔ 只看标题和封面就总结。
2. **学到的必须写成规矩，写进这家店的规矩本**（memory 里的三栏，见第三节）。只在这次对话里说一遍，下次就忘了，等于没学。
3. **店主说过一次的事，不让他说第二次。** 每次开工先读规矩本。

## 一、学一条参考片

**1. 打开看。** 用工具包的浏览器打开店主给的链接（Instagram、TikTok、小红书、抖音、YouTube 都一样）。登录是店主自己的事，没登录就请他登一下。打开后：
- 读这条帖子的标题、正文、标签、点赞评论数、前几条评论。
- 从头播放，每 1 秒截一帧，直到播完；有字幕的帧放大看清字。
- 能取到声音就转写旁白（`render/speech_review.py`）；取不到就照字幕记台词。
- 店主直接给了视频文件：`render/check.py --sheet` 抽帧 + 转写。

**2. 拆成风格卡。**

| 项 | 填什么 |
|---|---|
| 总长和镜头数 | 例：28 秒，9 个镜头，平均 3 秒一镜 |
| 第一秒 | 画面是什么、有没有人在动、第一句话或第一行字 |
| 结构 | 按时间写 3～5 段：每段几秒、在讲什么 |
| 画面类型 | 手部特写 / 人物 / 环境 / 产品，各占几镜 |
| 人 | 有没有人、露不露脸、对不对镜头说话 |
| 声音 | 旁白 / 人物说话 / 只有音乐；语速；口吻 |
| 字幕和大字 | 位置、每屏几个字、有没有标题大字 |
| 结尾 | 最后一镜和最后一句 |
| 标题和正文 | 写法（问句、数字、一句感受），不抄原文 |
| 它为什么有人看 | 结合数据和评论写一句：观众在评论里说的是什么 |

**3. 讲给店主听，三句话**：这条片的节奏、它为什么抓人、我们学哪三点、哪一点学不了用什么代替。店主说对才存（存 `style_profile`，一家店最多留 3 张卡）。

**4. 马上用一次。** 下一条片的结构、镜头数、每镜秒数、开场、口吻、字幕样式照卡；内容仍然来自这家店的档案和这周的角度。成片和参考片并排给店主看一眼。

**5. 店主给的是一个博主的主页链接**（不是单条视频）：
- 打开主页，记下这个号是做什么的、多少粉丝、多久发一条。
- 按播放量或点赞挑最高的 3 条和最近的 2 条，每条照上面 1～2 步拆。
- 写一张「这个博主的套路」：5 条里**重复出现**的做法（同一种开场、同一种结构、同一个时长、同一种口吻），只出现一次的不算。再写一句：播放高的那几条和普通的差在哪。
- 讲给店主听、存卡、下一条片用一次，都和单条一样。

## 二、学店主的意见

店主对任何一条片说了「不要 / 不喜欢 / 太 X 了 / 以后都 Y」：
1. 先改这一条。
2. 再把它写成一条规矩，带上店主原话和日期，记进规矩本的「一定不能做」或「效果好」。
3. 写完念给店主确认一句：「我记成了：以后……，对吗？」
⛔ 把一条具体意见放大成一片禁区（店主说「这条别讲价格」≠ 以后都不许讲）；拿不准是只管这一条还是以后都管，就问一句。

## 三、学发布数据，规矩本三栏

每条片发出 24 小时和 48 小时各读一次数据（播放、看完率、评论、有没有人来问），和这家店前几条比。然后更新 memory 里的规矩本：

- **一定不能做**：店主明说不要的；连续两条数据明显差的做法。每条带原话或数据。
- **效果好**：数据明显好的片，它的开场、角度、时长是什么。下一周多做一条同类的。
- **可以试**：从参考片学来、还没验证的做法。每周最多试一个，一次只改一处，这样才知道是哪一处起的作用。

「可以试」里的做法，试过两次数据都好 → 挪到「效果好」；都差 → 挪到「一定不能做」。

## 四、不能做的
⛔ 搬参考片的画面、音乐、原声、原文案；⛔ 出现参考片里的人、店名、商标；⛔ 把参考片上传当参考图去生成；⛔ 学不了的硬做（真人对镜头口播、实拍探店、我们没有的特效，照实告诉店主用什么代替）。

和「每日出片规范」第四节冲突时：第四节管底线，本技能学来的东西管底线之上怎么排。

## English summary
How to learn: always inspect the original (open the owner's link in the toolkit browser, read the post text, metrics and comments, capture a frame every second, transcribe or read captions), break it into a style card (length/shots, first second, timed sections, shot types, people, voice, captions, ending, title pattern, why it works), confirm with the owner in three sentences, store it, and apply it to the very next film. Turn every owner comment into a dated rule with their own words and confirm it; never widen one comment into a blanket ban. Read 24h/48h metrics and maintain a three-column rulebook in memory — never do / works well / worth trying — testing one change a week. Never copy footage, audio, wording, people or brands.
