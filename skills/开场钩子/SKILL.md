# 开场钩子（前 3 秒）

> 方法参考开源项目 adam-video-hooks（MIT License），按小生意营销短视频改写。

## 四步结构（所有强开场的底层）
```
① 即时语境 → ② 目标观众代入 → ③ 真反转 → ④ 留下来的回报
```
- **① 即时语境**：1–2 秒内观众知道在讲什么。「这太疯狂了…」=废；「开美甲店的，你群里天天发图，新客人却一个没来…」=活。
- **② 观众代入**：让对的人觉得「这是说我」——点名痛处、想要的结果、身份压力、熟悉的瞬间。
- **③ 真反转**：真的换个角度看，不是加个「但是」。「你以为是 A，其实是 B」「大家怪表面，真卡点在深处」。
- **④ 回报**：让观众知道看完能带走什么——用他自己的大白话说破的门道、一个诊断、一组前后对比。最常缺的就是这一步。

## 四审（任一不过就重写）
1. 话题 1–2 秒内出现了吗？（铺垫 = 划走）
2. 一个累了一天的人能不能一听就懂？
3. 目标观众（具体到哪类店）第一句就知道是说他吗？
4. 有没有反转 / 悬念 / 说破的门道 / 强欲望之一？

## 七测（结构对了也可能没劲）
1. 欲望够鲜活吗？「提升文案」弱；「让刷到的人忍不住私信来问」强。
2. 门道用观众自己的话讲了吗？不要用理论名词当高潮。
3. 反转是真的换角度，还是换了个说法？
4. 看完观众能成为更好的自己（会做内容的老板）吗？
5. 观众脑子里能放出那个画面吗？
6. 讲的是真实的疼和结果，还是泛泛的「变得更好」？
7. 顺序：欲望 → 说破门道 → 证据 → 自然收住；别用证据开头再接泛话题。
> 两项以上不过，重写。

## 五种开法
① 反直觉断言 ② 点名冲突 ③ 悬念缺口 ④ 结果前置 ⑤ 反着说：从「怎么一定失败」倒推「怎么活」。

## 红旗短语（出现就重写）
「今天我们聊聊…」「给大家几个小技巧」「教你提升…」「现在都在用…」「想涨流量就要…」；讲课腔「说白了…」「所以你要…」。

## 用法
- 只有想法：先问三问——观众此刻正疼什么？反转是什么？带走的门道怎么用他的话说？再按四步拼。
- 已有内容、开场弱：从正文找最狠的反转句提到第一句，再补回报。
- 判断开场：按四步逐项打分 + 四审 + 七测，指出缺哪步。

## 底线
具体不空泛；证据要真实（观众亲历的场景、有出处的原话或公开数据）；⛔ 编案例、价格、年数、效果数字，标「示意」也不行；⛔ 大师腔、假笃定、空亢奋。
